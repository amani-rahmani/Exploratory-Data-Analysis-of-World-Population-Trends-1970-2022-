1️⃣ Project Overview

This project explores global population trends over the last five decades. Using Python, Pandas, and Matplotlib/Seaborn, the analysis visualizes population growth, density, and distribution across countries and continents. The goal is to uncover insights about population dynamics and their global impact.

2️⃣ Key Questions Explored

Which countries experienced the largest population growth between 1970 and 2022?

How is population distributed across continents?

Does population density correlate with growth rate?

Which countries contribute the most to world population share?

3️⃣ Visualizations

Population growth over time (line charts)

Total population by continent (bar chart)

Density vs growth rate (scatter plot)

Heatmap of continent population growth
